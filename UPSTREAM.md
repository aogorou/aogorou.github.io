# Upstream template

- Project: Academic Pages, derived from Minimal Mistakes
- Repository: https://github.com/academicpages/academicpages.github.io
- Imported commit: `c77da751a8124450d5fb818056c0cf081fea08e1`
- License: MIT, copyright (c) 2016 Michael Rose, retained verbatim in `LICENSE`

Imported runtime files include `_sass/`, `_includes/`, `_layouts/`, the UI text data, JavaScript, and the Font Awesome fonts used by the theme. Example posts, publications, teaching records, comments, unrelated workflows, sample photographs and template favicon artwork are not included.

## Local changes

- Added Aoi Murakami's English and Japanese profile, research, CV and publication records.
- Added language-aware navigation and sidebar settings.
- Added researchmap links and a publication layout that displays verified years without inventing publication days.
- Replaced the example favicon with an original typographic AM icon.
- Added minor Japanese typography and accessibility styles.
- Kept third-party notices in source and in publicly available license text files.
- Disabled comments and analytics. Academic icon fonts are not loaded because the configured profile links use Font Awesome.
- Made MathJax opt-in (`mathjax: true` in a page).
